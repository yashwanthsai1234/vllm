    Words used here

    model
    The set of learned numbers that writes text.
    vLLM
    The program that runs the model on GPUs.
    inference
    Running the model to write new text, one token at a time.
    token
    A small piece of text. In these examples, one word.
    vector
    A list of numbers.
    layer
    One floor of the model's tower. The model in the issue has 48 layers.
    query, key, value
    Three vectors per token: a question, a name tag, and a backpack.
    attention layer
    A layer that compares the newest token with itself and all old tokens.
    state layer
    A layer that keeps one small summary of fixed size (in the issue: GDN layers).
    KV cache
    The memory that stores the keys and values of old tokens.
    block
    One page of the KV cache. In the vLLM test, one block holds 16 tokens.
    head
    One copy of the attention math. A layer runs some heads side by side.
    group
    A set of layers that share one row of blocks. Different kinds never share a group.
    GPU
    The chip that does the math.
    stage
    The part of the model that one GPU runs.
    plan
    The KV cache memory to reserve on one GPU, layer by layer.

    Sources: issue 54711, change 60234, change 61452.
